# V5 第四轮真实房源调查 — 2026-10-10

本轮继续按“闹中取静”模型收敛，不扩大通用系统。重点是：50–60㎡、1–2楼、25–35万优先、成熟生活圈、低密多层、边户优先，且必须把明显噪声风险先做否决。

## 一、当前第一顺位仍是煤建四处

### 煤建四处 54.16㎡ / 27万 / 明确1楼 / 共4层 — A-/B+

- 当前公开市场仍可检索：2室1厅、54.16㎡、27万、低层/共4层、南向，标题明确“此房1楼”。
- 旧仓库资料显示小区总体规模约154户/11栋，当前候选中体量较小。
- 优点：面积、价格、1楼、低层楼栋、小体量社区同时命中。
- 当前未解决：是否边户/东边户；卧室是否朝院内；一楼窗外是否为停车位/公共通道；楼上户型及撞击声；具体楼栋与煤建路/公交/未来轨交施工或运营声源的关系。
- 结论：继续第一顺位。只有补齐楼号、单元和窗向后，才能决定是否立即看房。
- 来源：https://www.fang.com/houses/esf_194620_xz/c20%2C100-d230%2C150-g22%2C4/

## 二、中枢95号院继续加分，但房源楼层仍未闭合

### 中枢95号院 50㎡ / 25.6万 — B+

- 当前安居客公开列表仍能检索到：中枢95号院，房东直卖，2室1厅，50㎡，25.6万，约5120元/㎡。
- 但是公开列表没有给出精确楼层，因此不能把它误写成1/2楼。
- 58爱房小区资料：住宅、70年产权、2000年、多层、单位自建/单位自管、139户、绿化率30%、容积率1.20、地面车位约30个、统一供暖。
- 2026年10月公开参考均价约5908.5元/㎡；25.6万/50㎡约5120元/㎡，低于该参考值，但不能仅凭这一点判断便宜或存在问题。
- 社区形态非常契合用户：小体量、多层、低容积率，且位于中枢南街成熟生活圈。
- 当前最大缺口：精确楼层、边户/东边户、具体楼栋、窗向、与中山南路/中枢街商业和车流的空间关系。
- 结论：只要确认1楼或2楼，就立即与煤建四处并列第一梯队；若3楼以上则按用户硬偏好降级。

## 三、从“单套95号院”扩大为“中枢街片区候选池”

- 55.95㎡ / 30万 / 南向；精确楼层未在聚合推荐中显示。
- 57.69㎡ / 24万 / 东向；精确楼层未在聚合推荐中显示。注意：“东向”不是“东边户”，不能混淆。
- 57.81㎡ / 31.8万 / 南向；已找到独立页面，实际为中楼层/共7层，因此不符合1–2楼，降级。
- 62.29㎡ / 30万 / 南北；独立页面显示高楼层/共7层，面积也略超，因此排除主候选。

## 四、福润佳苑仍为第一梯队，但“新一些”不能替代安静证据

### 福润佳苑 54.62㎡ / 33万 / 1楼 / 2012年 — B+

- 当前公开详情页仍有效：1室1厅1卫、54.62㎡、33万、底层/共7层、板楼、南北、毛坯、2012年，2026-09-04发布。
- 距1号线工农路站约787米；页面描述门口有公交站、配套成熟。
- 同小区页面仍展示该54.62㎡/33万房源；2026年8月/6月有较新的社区成交样本，但面积更大，不直接用于给本套定价。
- 优点：房龄和公共空间外观相对老小区更有希望，面积/价格/1楼均命中。
- 风险：一室户型；小区规模不算小；门口公交与具体楼栋关系未知；边户、停车、单元入口、楼上撞击声均未排除。
- 结论：继续第一梯队，但目前“安静潜力”的证据仍弱于煤建四处和低楼层成立时的中枢95号院。

## 五、煤港小区维持B级，不因“一楼带院”自动加分

### 煤港小区 59.3㎡ / 37.8万 / 一楼带院 — B

- 58当前小区页继续显示：59.3㎡、1室2厅、37.8万、一楼带院；同时还有64.2㎡/28万/2楼、50.96㎡/36万等房源。
- 生活便利度强，但煤港路成熟商业/交通意味着外部噪声必须楼栋级核验。
- “带院”对独居体验有吸引力，但如果院外是停车、菜市通道、单元入口或道路，它反而可能比普通二楼更吵。
- 结论：只有确认院子朝小区内部且与煤港路/菜市/停车口隔离，才值得安排现场看房。
- 来源：https://xz.58.com/fangjiazoushi/meigangxiaoqu/

## 六、黄河新村继续等待，不为生活圈偏好破坏硬条件

- 当前公开市场仍能看到60.25㎡/34万房源，但独立/聚合页面显示为中楼层/共5层，不符合1–2楼规则。
- 已确认低层的黄河新村房源普遍价格更高，例如67㎡级低层约52万、65.59㎡一楼带院约58万，已经偏离面积/价格策略。
- 结论：黄河新村生活圈很符合“楼下便利”，但当前没有发现一套同时闭合50–60㎡ + 1/2楼 + 25–35万。继续等，不强行入选。

## 七、本轮排序

1. 煤建四处 54.16㎡ / 27万 / 明确1楼 —— 当前证据最完整，继续核楼栋和安静性。
2. 中枢95号院 50㎡ / 25.6万 —— 社区形态非常符合；精确楼层一旦确认1/2楼即可并列第一。
3. 福润佳苑 54.62㎡ / 33万 / 1楼 —— 较新，但密度与公交/停车关系待核。
4. 中枢街片区 55.95㎡/30万、57.69㎡/24万等 —— 价格面积很好，但楼层未闭合，继续追。
5. 煤港小区 59.3㎡ / 37.8万 / 一楼带院 —— 生活便利强，先做交通/院外噪声否决。
6. 黄河新村 —— 等真正满足低楼层与价格的正确房源。
