# V5 第九轮：安静优先继续收敛 — 2026-10-10

本轮不扩大工程架构，只继续找“面积/楼层/价格已闭合，而且具备安静潜力”的真实候选。价格和成交最终仍以贝壳为主；房天下、58、安居客仅用于发现和字段交叉核验。

## 1. 新强候选：中煤建安六处 60㎡ / 29万 / 标题明确2楼 — 安静=UNKNOWN

当前房天下文沃市场板块仍能检索到：

- 标题：大润发建院旁煤建六处2楼简装老证随时过户；
- 2室1厅；
- 60㎡；
- 低层/共6层；
- 南向；
- 29万，约4834元/㎡；
- 满五年；
- 距3号线南三环路站约1023米。

同小区另有59.23㎡/30万/中层共4层房源，但不符合1–2楼偏好。

社区公开资料：

- 中煤建安六处小区；
- 普通住宅、70年产权；
- 2005年；
- 多层；
- 单位自建/单位自管；
- 366户；
- 容积率1.20；
- 绿化率30%；
- 地面车位80个；
- 地址在风华南路、近煤建校北巷。

优势：面积、价格、明确2楼、低容积率、多层、2005年、单位院落型社区同时命中，是本轮新出现的最强硬条件候选之一。

风险：小区位于文沃市场/建筑学院/江苏师范大学生活圈，附近公交线路很多，且风华南路、上海路、学校/市场活动可能形成白天和晚间噪声；366户对“极小体量社区”不算小；停车位相对户数偏少，需排除一楼/二楼窗前停车和电动车集中区。三环内外及具体楼栋相对南三环的位置仍需单独确认。

结论：提到第一梯队，但安静仍为UNKNOWN。下一步必须核具体楼栋、卧室窗向、是否背风华南路/文沃市场/学校、窗外停车和单元入口，再决定是否去现场。

## 2. 煤建四处 54.16㎡ / 27万 / 明确1楼 — 安静=UNKNOWN

继续保留第一梯队。当前仍没有发现新的硬伤，也仍没有拿到足以证明“安静”的楼栋级证据。

关键缺口仍是：楼号/单元、边户、卧室朝向、一楼窗外停车/公共通道、楼上户型与排水/撞击声、与道路/公交/轨交的真实空间关系。

## 3. 煤建四处 53.04㎡ / 29万 / 低层共3层 — 安静=UNKNOWN

当前房天下仍可检索：53.04㎡、3室1厅、29万、低层/共3层、南向。

这套的建筑形态很吸引人：总楼层只有3层，面积价格合适。但“低层”仍未闭合为精确1楼还是2楼，所以不能提到前两名。

结论：只要精确楼层确认是1/2楼，就立即提级。

## 4. 祥和小区 55.72㎡ / 32.8万 / 标题明确二楼 — 安静=UNKNOWN，继续保留但风险上升

当前房天下仍能检索到：

- 2室1厅；
- 55.72㎡；
- 32.8万；
- 低层/共7层；
- 南北向；
- 标题明确“二楼精装加盖一间南北通透设施齐全”。

小区公开资料：1999年、约2221户、容积率1.30、绿化36%、约300个地面车位；公开评测同时提示停车紧张。附近公交站多，商圈成熟。

因此这套不能只因为“2楼+32.8万”提级。需要优先核：

1. “加盖一间”是否计入房本面积、是否合法、是否影响交易；
2. 具体楼栋是不是靠祥和菜场、公交密集点、主路、停车口；
3. 是否边户；
4. 卧室窗向和楼上噪声。

结论：仍保留，但排序低于煤建六处和煤建四处。

## 5. 祥和小区花园楼 — 继续作为高价值等房池

公开资料仍显示：2005年、多层、48户、容积率1.20、单位自管、80个地面车位。社区形态非常符合“外面成熟、里面小体量”的模型。

目前仍未找到闭合50–60㎡ + 1/2楼 + 25–35万的具体在售，因此不拿不合格房源凑数。

## 6. 新观察：煤建路东一巷6号小区

58资料显示：2018年、多层、24户、容积率1.20、单位自管、70年住宅产权。

这个社区体量非常小，理论上比很多老大社区更符合“闹中取静”的院落型目标。但当前没有找到50–60㎡ + 1/2楼 + 25–35万具体挂牌。

结论：进入高优先级等房池。
