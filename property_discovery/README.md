# Property Discovery

V3在真实贝壳挂牌上开展六维住宅声学调查，不推荐购买，不扩展人生规划。

默认：仅贝壳、徐州、40-60平方米、最低价不限（0作为查询下界）、最高50万元，电梯或1-3楼优先。三环边界未知就写未知。0元挂牌需人工核实，不计有效候选。

本轮采用用户最新调查优先级：安静 > 隔音 > 居住密度 > 价格。原六项评分权重不改，工程调查只接入安静30分、隔音20分，不重复计分；未知不打分。三环边界另核，南区环外补充（包括用户明确允许的碧水湾）单列；不将整个行政区当作允许范围。

## 运行

需要Python 3.9+标准库、已安装的 `browser-harness` 及可正常连接的Chrome：

```sh
python3 -m property_discovery.discover --target 20
python3 -m property_discovery.refresh --skip-existing-communities
python3 -m unittest discover -s tests -v
```

输出 `candidate_properties.md`、逐套下钻 `acoustic_investigations.md`、`data/latest.json` 和追加的 `data/runs/<运行ID>.json`。旧快照不覆盖，新轮记录parent_run_id；所有来源、时间与失败原因可追溯。`acoustic_reference.md`记录官方规范核对、构造机制和检测流程；版本核验不足明确列出，不伪称全部完成。

`search_plan.json`包含18个区域/片区及南区补充搜索，公开面积/总价筛选URL；每页只读公开列表。先完成有限覆盖，再按小区ID和区域轮流读取详情，以20个不同小区线索、60套详情或访问限制为停止条件，每小区最多2次详情尝试，每次间隔至少2秒。不拿20套同小区房源当完成；首页一小区一代表，生活冲突对象延后展示。`--url`可指定贝壳公开列表（重复参数），其他平台在V3不能作为挂牌/成交来源。

`refresh`修复地图/社区资料读取或补查已有快照线索，保留旧失败记录。正常点击医疗/教育/购物地图标签，核对已选择标签及返回类别才保存结果；窗口聚焦是点击前提，失败标unavailable，不把空结果当无医院。最多通过12个`--listing-url`补查已观察且未访问的房源URL，不接受未发现的随意URL。`--skip-existing-communities`在已有社区时间戳时仅离线重评估，首次未取得资料仍正常访问。

公园、快速路等人工地图复核存`data/map_reviews.json`，仅对应小区参考点；公开地图截图只含地图，逐张检查后保留。不能通过该点假装知道楼栋/卧室位置。

## 边界

- 浏览器只执行正常导航及只读DOM提取；不读取Cookie、账号、私信，不访问私有接口、不修改登录状态。
- 使用Chrome现有会话不意味着访问私有内容；仅提取普通在售卡片、公开住宅属性和小区地址。若内容要求登录则记录并停止，绝不登录或规避。
- 验证码、登录墙、反爬页面出现即停止该平台本轮访问，不解验证码、不换IP/账户重试。
- 贝壳列表、详情、小区字段和公开成交记录已读取；旧辅助平台适配器仅保留历史兼容，不在V3采集使用。
- 商办公寓/非普通住宅排除；小区名称含公寓不能独自证明用途。住宅字段与办公/民宿描述冲突需暂停优先调查；用途或平台产权字段缺失保留在线索，不当作已确认住宅。公开产权字段齐备也不等于登记产权清晰。
- 低/中/高楼层不转成具体楼层；总层数不证明电梯；建筑结构不证明隔音；标题不证明安静。
- 报价仅判断是否在预算内；没有可比成交就不评价格合理性。跨平台相似房源不擅自当作同一套去重。
- 原始HTML、整页文字、身份信息、聊天及经纪人电话不保存。测试数据仅用于测试，不写入真实房源报告。
- 图片URL若文件名含类似手机号的11位数字，保守移除，即使可能是平台编号；快照注明过滤，不冒称完整原网页归档。

## 本轮与旧结论的关系

V1的“有10套挂牌线索，但安静/电梯未核”保留在旧快照，不改成当时已核验。V2/V3修正默认排序、小区数量停止和地图交互问题，扩充不同小区与真实环境证据；没有A级实测或B级构造资料仍不认定隔音合格。正式现场检测前须补齐尚缺官方评价标准版本，不能用程序字段数量掩盖证据不足。
# V4 既有房源收敛

`python3 -m property_discovery.review_existing --refresh-focus` 只重新访问已有四个起点房源，不扩展搜索；遇访问门槛停止，保留旧字段和失败记录，不冒充刷新成功。省略参数可离线重新生成报告，保留原始采集日期。

明确1-3楼且字段无冲突，即使电梯未知也通过楼层偏好初筛；平台声明不是现场确认。三环采用政府道路关系说明与公开OSM主线闭合几何，小区参考点近似转换，750米内保守待核；不使用行政区替代，未取得具体楼栋测绘。

`candidate_properties.md` 最多5套取证型看房对象，未通过地理/楼层/用途或缺具体复核的对象单列。实际隔音和产权未知不冒充购买合格；完整原始资料与现场缺口保留在下钻报告。V3南区环外放宽不沿用，环外和边界附近分别存储在 `data/outside_properties.json`。
