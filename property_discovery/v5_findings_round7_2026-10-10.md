# V5 第七轮：安静硬门槛重搜 — 2026-10-10

本轮继续从零重搜，不为了“必须找到”而放宽证据标准。价格只以贝壳作为最终估值/成交依据；房天下、58、安居客等只做发现与字段交叉核验。

## 核心规则

- 安静不是加分项，而是购买前置条件。
- UNKNOWN 不得冒充 PASS。
- 字段冲突（尤其楼层、户数、边户）一律降级，直到取得更新、更具体证据。
- 先排铁路/货场、主干道、医院急诊、学校操场、菜市场装卸、停车出入口、单元门、电动车集中点、设备低频，再谈价格与装修。

## 本轮确认/修正

### 1. 煤建四处 54.16㎡ / 27万 / 明确1楼 / 共4层 — 当前第一顺位，安静=UNKNOWN

仍是目前“面积 + 价格 + 精确低楼层 + 低层建筑 + 小体量社区”证据组合最完整的对象。下一步必须补楼号、单元、是否边户、卧室朝向、一楼窗外是否停车/公共通道、楼上户型和排水/撞击声。

结论：没有发现足以把它降级的新证据，继续第一顺位做楼栋级调查。

### 2. 中枢95号院 50㎡ / 25.6万 — 社区形态最符合目标之一，安静=UNKNOWN

公开列表仍能检索到50㎡/25.6万房东直卖线索；社区资料约139户、多层、容积率1.20、单位自管。生活圈成熟，具备“外面繁华、院内可能安静”的结构性潜力。

关键缺口仍是精确楼层。如果不是1/2楼，则按当前硬偏好降级；若是1/2楼，再继续查具体楼栋是否背街、边户、卧室朝向和商业/医院车流关系。

### 3. 福润佳苑 54.62㎡ / 33万 / 1楼 — 继续第一梯队，安静=UNKNOWN

面积、价格、1楼、房龄较新均符合，但公交/停车/单元入口/楼上撞击声尚未排除。小区规模不算小，因此不能仅凭“2012年前后”推断安静或隔音更好。

### 4. 培正巷 54.32㎡ / 26万 — 从高优先降为“楼层冲突待核”，安静=UNKNOWN

旧58抓取标题曾明确写“2楼南北通透”，但近期房天下同面积同价格条目标为“中层/共5层、南向”。两者可能是不同房源，也可能是旧数据/字段冲突。

因此：
- 不再写“已确认2楼”；
- 不进入立即看房名单；
- 只有当前在售、精确楼层=1/2楼重新闭合后才提级。

同时，小区总户数公开口径也存在约61户与更大数字的冲突，不能为证明低密度而选有利数据。

### 5. 金泰小区 — 新增观察池，当前有58㎡级低总价线索，但楼层未闭合

房天下小区页可见：
- 58.58㎡ / 32万 / 2室1厅；
- 57.33㎡ / 39万 / 2室1厅；
- 58.32㎡ / 45万 / 明确3楼。

说明该小区确有50–60㎡小户型供给，且价格存在30多万区间。但当前最便宜的58.58㎡/32万没有取得精确楼层；已明确的58.32㎡是3楼，不符合1–2楼偏好。

另外，小区体量公开口径较大（链家资讯约1414户/50栋；其他平台也有不同口径），因此它不是“小体量院落”典型。除非后续出现院内、1/2楼、边户且安静证据明显的具体楼栋，否则只做观察，不提到煤建四处/中枢95号院之前。

### 6. 煤建路4号小区 — 社区形态继续加分，但还没有正确的具体房源

58资料：2000年、多层、约160户、容积率1.40、单位自管。这个社区形态符合目标，但本轮没有找到已经闭合“50–60㎡ + 1/2楼 + 25–35万”的当前具体挂牌。

结论：继续定向等待，不用不合格房源凑数。

### 7. 税务局宿舍 60㎡ / 29万 / 低层共3层 — 暂时剔除

房天下聚合出现“税务局宿舍 60㎡ / 29万 / 低层 / 共3层 / 南北”的漂亮线索，但搜索无法可靠确认这是徐州主城区哪一个具体税务局宿舍，跨城市同名小区很多。

结论：在位置、产权、小区身份闭合前不得纳入徐州候选，更不能因为数字漂亮就推荐。

## 本轮没有提级的典型房源

- 黄河新村：50–60㎡供给很多，但当前能确认楼层的合价房源仍没有闭合1/2楼；继续等正确房源。
- 纺南小区：50–60㎡房源不少，生活便利强，但目前检索到的合价房源多为中高楼层；不为小区偏好破坏楼层硬条件。
- 惠工/铁路周边：存在二楼低价房，但铁路/货场相关风险仍属于高权重否决因素，不因便宜提级。
